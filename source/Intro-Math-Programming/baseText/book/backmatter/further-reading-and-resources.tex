\chapter{Bacaan Lanjutan dan Sumber Daya}

Buku teks dan catatan gratis berikut dapat menjadi rujukan alternatif atau pelengkap yang berguna untuk topik-topik yang dibahas dalam buku ini.

\paragraph{\textbf{Optimisasi dan Pemrograman Linier}}
\begin{itemize}
\item \href{http://www.optimization-online.org/DB_FILE/2013/12/4161.pdf}{A First Course in Optimization} oleh Jon Lee
\item \href{https://web.stanford.edu/~boyd/cvxbook/}{Convex Optimization} oleh Boyd dan Vandenberghe
\item \href{https://www.springer.com/gp/book/9783540306979}{Understanding and Using Linear Programming} oleh Matousek dan G\"artner (gratis melalui Springer dengan akun universitas)
\item \href{http://math.mit.edu/~goemans/18310S15/lpnotes310.pdf}{Linear Programming Notes} oleh Michel Goemans (MIT)
\item \href{https://www.researchgate.net/publication/411022416_Decision_Modelling}{Decision Modelling} oleh David M. Tulett (teks terbuka tentang analisis keputusan dan pemodelan optimisasi)
\end{itemize}

\paragraph{\textbf{Matematika Diskret dan Kombinatorika}}
\begin{itemize}
\item \href{http://discrete.openmathbooks.org/dmoi3.html}{Discrete Mathematics: An Open Introduction} oleh Oscar Levin (CC-BY-SA)
\item \href{http://www.rellek.net/book/frontmatter-1.html}{Applied Combinatorics} oleh Keller dan Trotter (CC-BY-SA 4.0)
\end{itemize}

\paragraph{\textbf{Landasan Matematika}}
\begin{itemize}
\item \href{https://open.umn.edu/opentextbooks/textbooks/book-of-proof}{Book of Proof} oleh Richard Hammack (teknik pembuktian)
\item \href{http://linear.ups.edu/html/fcla.html}{A First Course in Linear Algebra} oleh Robert Beezer
\end{itemize}

\paragraph{\textbf{Pemrograman}}
\begin{itemize}
\item \href{https://open.umn.edu/opentextbooks/textbooks/a-byte-of-python}{A Byte of Python} (CC-BY-SA, buku teks daring gratis)
\item \href{https://coin-or.github.io/pulp/}{Dokumentasi dan Tutorial PuLP}
\end{itemize}

\noindent Untuk perangkat lunak optimisasi, tutorial pemecah, dan sumber daya bahasa pemodelan, lihat Lampiran~\ref{app:software}. Kode contoh tambahan tersedia di \url{https://github.com/open-optimization/open-optimization-or-examples}.
