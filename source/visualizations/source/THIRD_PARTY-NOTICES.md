# Pemberitahuan ketergantungan visualisasi

Paket sumber ini tidak menyertakan `node_modules` atau bundle hasil bangun.
`package-lock.json` memakukan seluruh graf ketergantungan npm, termasuk URL
tarball dan integritas SHA-512. Ketergantungan langsungnya adalah:

| Paket | Versi | Lisensi |
|---|---:|---|
| React | 18.3.1 | MIT |
| React DOM | 18.3.1 | MIT |
| KaTeX | 0.16.11 | MIT |
| Lucide React | 0.460.0 | ISC |
| Vite | 5.4.11 | MIT |
| @vitejs/plugin-react | 4.3.4 | MIT |

Teks lisensi dan pemberitahuan lengkap ikut hadir dalam setiap paket yang
diambil oleh `npm ci`. Hak atas sumber interaktif edisi ini dipetakan secara
terpisah dalam `LICENSES/README.md` pada akar rilis.
